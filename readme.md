## What is Joystick Diagrams?

Joystick Diagrams reads your game config files and generates hardware-accurate visual diagrams of every button, axis, hat switch, and modifier on your controllers.

No manual data entry. No design skills needed. Always in sync with your actual bindings.

**If you've ever found yourself:**
- Memorizing bindings through repetition
- Building reference cards in PowerPoint or Photoshop by hand
- Printing ugly, unreadable binding lists from the game settings
- Pausing mid-flight to check which button does what

...this is what I built it to fix.

## How It Works

1. **Setup.** Install the app, add your game plugins, point each at the game's config folder. Profiles and devices are discovered automatically.
2. **Customise.** Browse profiles by game and aircraft. Rename actions with custom labels. Hide devices you don't need.
3. **Export.** Pick your profiles, choose a template for each device, tune the live preview if needed, select SVG or PNG, then export.

### Smart export text layout

Long game action names can be automatically fitted into template label boxes. The feature is opt-in under **Settings → General → Export Text Layout**, so existing exports remain unchanged until it is enabled.

The **Export** page also includes a live SVG preview. Selecting a profile renders the same `populate_template()` result that will be written during the real export. For large draw.io SVGs, the generated bytes are written only to a private temporary preview directory and rendered with Chromium, avoiding WebEngine data-URL limits while keeping `foreignObject` text accurate. Text-layout controls are available next to the preview and persist to the same core settings, with a short debounce so font size, wrapping, line-count, and ellipsis changes update almost immediately. The preview supports mouse panning, wheel zoom, `+`/`−` controls, and **Fit**.

The core export engine can:

- wrap long binding labels, preferring `|` separators between multiple actions;
- set a global binding-label font size or preserve the template's original size;
- progressively shrink long labels down to a configurable minimum font size;
- target a configurable number of characters per line and maximum line count;
- optionally truncate text with an ellipsis when it still cannot fit;
- apply the same behavior to button, axis, POV, and modifier-action labels;
- handle normal SVG `<text>` / `<tspan>` labels and simple HTML labels inside SVG `foreignObject` elements.

Template authors can override the global settings for an individual SVG `<text>` or HTML label using optional attributes:

```xml
<text
  data-jd-max-chars="22"
  data-jd-max-lines="2"
  data-jd-font-size="10"
  data-jd-min-font-size="8"
  data-jd-wrap="true"
  data-jd-shrink="true"
  data-jd-ellipsis="false">
  <tspan>BUTTON_1</tspan>
</text>
```

Use `data-jd-layout="off"` on a label to keep legacy one-line replacement for that specific element. Per-label attributes are optional; templates without them use the global settings.

## Installation

### Windows

1. Download the latest [release](https://github.com/Rexeh/joystick-diagrams/releases)
2. Unzip to your preferred location
3. Run installer, and launch application

### Linux

1. Download the `joystick-diagrams-<version>-linux-x86_64.tar.gz` from the latest [release](https://github.com/Rexeh/joystick-diagrams/releases)
2. Extract it to your preferred location
3. Run `./run.sh` from the extracted folder

There is no installer on Linux. Optionally run `./install-desktop.sh` to add an
application menu entry for your user (re-run it if you move the folder).

For setup guidance, see the [documentation](https://joystick-diagrams.com/setup/).

### Building from Source

```bash
git clone https://github.com/Rexeh/joystick-diagrams.git
cd joystick-diagrams
uv sync
```
